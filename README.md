# SURGINT

*Surgical Instrument Intelligence*

> **Status:** This project is under active development. APIs, configuration, and behavior may change.

A real-time vision system for surgical instrument trays, from detection to handling decision.

A moving camera observes a static tray. The system detects, classifies, and associates instruments across frames, maintaining a per-session inventory. A domain ontology encodes structured clinical instrument knowledge and resolves each inventory item to a handling decision.
